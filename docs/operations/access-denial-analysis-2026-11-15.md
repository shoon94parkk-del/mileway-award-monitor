## 남은 해결 절차

대한항공 또는 해당 서비스를 관리하는 보안 운영자가 위 시각과 대상 경로에 대응하는 보안 이벤트·거부 규칙을 확인해야 한다. 공식적으로 허용되는 일일 좌석 연동 방식, 사용 조건, 필요한 접근 허용 절차를 확인한 뒤 그 범위에서 수집 경로를 구성한다. 현재 연결된 계정에는 대한항공의 Akamai 보안 정책이나 로그를 변경·조회할 권한이 없다.

Akamai의 [공식 진단 도구 안내](https://techdocs.akamai.com/edge-diagnostics/docs/tools-scenarios-descriptions)는 오류 참조코드/GRN을 이용한 오류 요약·에지 로그 확인을 제시한다. 현재 공개 로그에는 원문 참조번호를 보관하지 않았으므로, 운영자에게 위 재현 정보와 발생 시각을 먼저 전달하고 필요한 추가 진단 항목을 확인한다.

클라이언트 수정과 테스트 통과를 실제 좌석 수집 성공으로 보고하지 않는다. 정상 복구의 최종 조건은 공개 UI 달력 확인, 전체 범위 수집, 유효한 새 게시, 운영 화면 반영이다. 현재 그 조건은 충족되지 않았다.
